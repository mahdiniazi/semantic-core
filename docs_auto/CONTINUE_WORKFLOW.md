# Continue Workflow — کار روزمره

## ۱. شروع روز

## ۲. در VS Code
- Ctrl+B (نمایش sidebar)
- آیکن Continue در sidebar
- یا F1 → Continue: Focus on Continue View

## ۳. کار با AI
- در پنل Continue بنویس درخواست
- دسترسی به MCP خودکار است
- مثال: "از ابزار get_project_status استفاده کن"

## ۴. ابزارهای MCP که AI می‌بیند
- get_project_status
- get_clues
- get_feedback
- get_handoff
- get_integrity
- get_tasks
- get_widgets
- get_roadmap
- get_propositions
- run_safe_query

## ۵. کارهای روتین
- دستور در ترمینال → AI
- تغییر DB → cycle.sh
- به‌روزرسانی اسناد → doc_generator.sh
- نسک جدید → capture_clue.sh
