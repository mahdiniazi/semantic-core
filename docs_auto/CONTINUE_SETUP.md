# Continue.continue — راهنمای راه‌اندازی

## چرا Continue؟
- نصب است (`continue.continue-2.0.0`)
- MCP را پشتیبانی می‌کند
- سبک‌تر از Cline
- Config ساده‌تر

## راه‌اندازی
1. `~/.continue/config.json` را با API key پر کن
2. VS Code را restart کن
3. Ctrl+Shift+P → "Continue: Focus on Continue View"
4. Continue sidebar → Settings → MCP Servers
5. project-monitor باید ظاهر شود

## API Options
- Anthropic: https://console.anthropic.com
- OpenAI: https://platform.openai.com
- OpenRouter: https://openrouter.ai
- Ollama (local): https://ollama.ai

## Config خودکار
`~/.continue/config.json` آماده است — فقط API key را عوض کن
