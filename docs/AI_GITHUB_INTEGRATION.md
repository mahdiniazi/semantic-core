# اتصال هوش مصنوعی به مخزن GitHub — راهکارها و سطوح

> **پیشنهاد اول کاربر:**
> «آیا امکان دارد هر وقت به هوش مصنوعی وصل می‌شوم، لینک GitHub پروژه را بدهم
> تا خودش هم کل موضوع را بخواند و هم از آخرین وضعیت پروژه مطلع شود؟»

> **هدف:** یافتن راهکار پیشرفته، کارآمد و بهینه برای اینکه هر AI جدید
> به‌سرعت پروژه را بفهمد و بر اساس آخرین وضعیت آن کار کند.

---

## ۱. خلاصه پاسخ

بله، این ایده کاملاً امکان‌پذیر است و در واقع یکی از بهترین کارها برای
افزایش بهره‌وری در همکاری با AI است. با دادن لینک GitHub، AI می‌تواند:

- کل پروژه را بخواند
- ساختار و اهداف را درک کند
- از آخرین وضعیت (کامیت‌ها، تغییرات) مطلع شود

نتیجه: نیازی به توضیح مجدد پروژه در هر گفتگو نیست و AI مستقیماً بر
داده‌های واقعی و به‌روز کار می‌کند.

## ۳. راهکارهای عملی برای پروژه هسته معنایی

### روش اول: اتصال مستقیم (ساده‌ترین)

- **ChatGPT:** `Settings → Apps → GitHub`
- **Claude:** دکمه `+` در چت → `Add from GitHub`

### روش دوم: GitHub MCP Server (پیشرفته‌ترین)

MCP یک استاندارد باز است که به AI اجازه می‌دهد مستقیماً با APIهای GitHub
تعامل کند. GitHub یک MCP Server رسمی ارائه داده که ابزارهایی برای:

- خواندن فایل‌ها
- مدیریت Issues
- مدیریت Pull Requestها

فراهم می‌کند. AI به‌جای دریافت یکجای کدها، به‌صورت هوشمندانه بخش مورد
نیاز را فراخوانی می‌کند.

### روش سوم: آماده‌سازی مخزن (بهترین برای این پروژه)

برای اینکه AI به بهترین شکل پروژه را درک کند، مخزن باید «خوانا» باشد:

1. **ایجاد `AI_HANDOFF.md`** — شامل هدف، ساختار، قوانین و وضعیت فعلی
2. **ایجاد `AGENTS.md`** — دستورالعمل‌های خاص عوامل هوشمند
3. **ابزارهای Context Engineering** — مثل `repoprompt` یا `agent-ready-kit`
4. **سازماندهی معنادار پوشه‌ها** — نام‌گذاری دقیق پوشه‌ها و فایل‌ها

## ۴. نکات کلیدی پرامپت‌نویسی

### قاعده ۱ — زمینه را مشخص کن
❌ «یک migration بنویس»

✅ «با توجه به بخش سوم قانون اساسی در `docs/strategic/01_constitution.html`
   که درباره تفکیک موجودیت و نقش است، یک migration بنویس...»

### قاعده ۲ — به فایل‌های خاص ارجاع بده
مسیر دقیق فایل را ذکر کن، نه توضیح کلی.

### قاعده ۳ — از AI بخواه تأیید کند
قبل از اجرا: «آیا این دستور با قوانین `AI_HANDOFF.md` سازگار است؟»

## ۵. پیشنهاد نهایی — سه گام

1. **گام اول:** قرار دادن `AI_HANDOFF.md` جامع در ریشه پروژه (همین سند
   به‌عنوان مرجع اصلی)

2. **گام دوم:** اتصال مخزن در AI مورد نظر (ChatGPT یا Claude)

3. **گام سوم:** در هر گفتگو، لینک مخزن ارسال شود و از AI خواسته شود
   ابتدا `AI_HANDOFF.md` را بخواند.

**نتیجه:** هر AI جدید بدون توضیح طولانی، درک درستی از پروژه پیدا
می‌کند و به‌عنوان همکار مؤثر عمل می‌کند.

---

## ۶. قواعد حاکم بر این راهکار

- **قاعده اول:** مخزن، مرجع اصلی است، نه چت.
- **قاعده دوم:** `AI_HANDOFF.md` باید در هر گفتگو به AI معرفی شود.
- **قاعده سوم:** لینک GitHub همیشه در ابتدای گفتگو ارسال شود.
- **قاعده چهارم:** اگر AI به فایل خاصی نیاز دارد، خودش می‌تواند با
  استفاده از لینک، آن را بخواند.
