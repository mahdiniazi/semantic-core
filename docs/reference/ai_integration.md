# مرجع ادغام با هوش مصنوعی

## سه روش اتصال AI به پروژه

### روش اول: دستی (ساده‌ترین)

هر بار که با AI چت می‌کنی:

۱. این دستور را بزن:
   ./scripts/dashboard.sh

۲. خروجی را در چت برای AI پیست کن

۳. بگو: «این وضعیت فعلی است. اولین وظیفه draft را اجرا کن.»

### روش دوم: لینک GitHub

هر AI که قابلیت خواندن GitHub دارد (ChatGPT، Claude، Cursor):

۱. لینک مخزن را بده:
   https://github.com/mahdiniazi/semantic-core

۲. بگو: «فایل AI_HANDOFF.md را بخوان، سپس وظایف draft را از scripts/dashboard.sh ببین.»

۳. AI خودش کل پروژه را می‌فهمد.

### روش سوم: MCP Server (پیشرفته‌ترین)

اگر AI مورد استفاده از MCP پشتیبانی می‌کند (Claude Code CLI، Cursor، Continue):

فایل .mcp.json در ریشه پروژه:

{
  "mcpServers": {
    "project-monitor": {
      "command": "node",
      "args": ["/home/cs/mcp-servers/pg_mcp_server.js"],
      "env": {
        "DATABASE_URL": "postgresql://monitor_ai:monitor_secure_1405@localhost:5432/project_monitor"
      }
    }
  }
}

سرور MCP در /home/cs/mcp-servers/pg_mcp_server.js است و سه ابزار دارد:

- get_roadmap — خواندن نقشه راه
- update_status — به‌روزرسانی وضعیت
- add_proposition — افزودن گزاره جدید

## پرامپت‌های آماده

### پرامپت شروع هر جلسه:

من روی پروژه semantic-core کار می‌کنم.
لطفاً اول این فایل را بخوان: AI_HANDOFF.md
سپس خروجی dashboard.sh را ببین و بگو اولین وظیفه بعدی چیست.

### پرامپت گزارش‌دهی:

این خروجی dashboard.sh است. لطفاً:
۱. آمار کلی را خلاصه کن
۲. سه وظیفه فوری بعدی را پیشنهاد بده
۳. اگر تعارضی در وضعیت‌ها دیدی، گزارش کن

### پرامپت افزودن گزاره:

از این متن، گزاره‌های اتمی استخراج کن:
[متن]
هر گزاره باید:
- یک جمله واحد
- قابل ارزیابی مستقل
- متصل به منبع و دامنه
خروجی را در قالب SQL INSERT بده.

## چرخه کامل AI

۱. AI وضعیت را از dashboard می‌خواند
۲. AI وظیفه بعدی را پیشنهاد می‌دهد
۳. کاربر دستور را اجرا می‌کند
۴. کاربر نتیجه را به AI می‌دهد
۵. AI آپدیت وضعیت را پیشنهاد می‌دهد
۶. کاربر آپدیت را در دیتابیس اجرا می‌کند
۷. commit و push

## قواعد طلایی AI

- AI نباید بدون خواندن AI_HANDOFF.md کار کند
- AI نباید مستقیم به دیتابیس بنویسد بدون تأیید کاربر
- AI باید دستور ترمینال را پیشنهاد بدهد، کاربر اجرا کند
- AI باید عدم قطعیت را بپذیرد
- AI نباید از DTC مستقیم به علت برود
