# پروژه ۲ — سامانه مدیریت تعمیرگاه هوشمند

## هدف
مدیریت پذیرش خودرو، تشخیص، ارجاع به سه سطح مهارتی، پیگیری تعمیر، گارانتی.

## فازهای WBS (پیشنهادی)
1. زیرساخت تعمیرگاه (پذیرش، بارکد، پروفایل خودرو)
2. تشخیص اولیه (DTC → درخت عیب‌یابی)
3. گردش کار سه‌سطحی (سطح ۱/۲/۳)
4. سوابق زنجیره‌ای (چند شعبه)
5. گارانتی و قیمت‌گذاری

## وابستگی به محصول ۱
semantic_core.db به‌عنوان موتور دانش تشخیصی.

## وضعیت
