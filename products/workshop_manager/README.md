# پروژه ۲ — سامانه مدیریت تعمیرگاه هوشمند

## هدف
پذیرش خودرو با بارکد/VIN، تشخیص درخت عیب‌یابی، ارجاع سه‌سطحی، سوابق زنجیره‌ای، گارانتی.

## فازها (WBS)
1. لایه پذیرش (بارکد، VIN، پروفایل خودرو)
2. لایه تشخیص (اتصال به semantic-core، درخت عیب‌یابی، رتبه‌بندی)
3. لایه گردش کار (سه سطح مهارتی، ارجاع، ردیابی گام)
4. لایه سوابق زنجیره‌ای (چند شعبه، جستجو، گزارش)
5. لایه گارانتی و قیمت (قطعه، خدمات، پیش‌فاکتور)

## ساختار
- db/workshop.db           — دیتابیس محصول
- scripts/                 — ابزارهای Python
- api/                     — API endpoints
- docs/                    — مستندات

## وابستگی
semantic_core.db (محصول ۱) به‌عنوان موتور دانش تشخیصی.
